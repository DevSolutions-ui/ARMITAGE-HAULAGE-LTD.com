# Armitage Haulage Ltd — Static Website

## Use locally

1. Keep `index.html`, `styles.css`, `script.js`, and the `assets` folder together.
2. Open `index.html` in a browser, or upload the whole folder to your hosting provider.
3. Replace the images inside `assets/` with your own company photography whenever ready.

The enquiry form and chatbot are frontend-only. The form shows a confirmation message but does not send email until a backend or form provider is connected.
